# Bronco Painting — Meta ads config (TEMPLATE)

Read by the `daily-ads-watch` skill, and by the weekly `meta-ads-checkup`.

**Setup:** copy this file to `.bronco-meta-config.md` in the same directory and fill in the
`FILL ME` values. That filename is gitignored — real account IDs stay out of git, and the
access token never goes in a file at all (see Credentials below).

## Account

| Key | Value | Notes |
|---|---|---|
| `meta_ad_account_id` | `FILL ME` | Format `act_XXXXXXXXXXXX`. Ads Manager → Settings → Ad account ID |
| `campaign_id` | `FILL ME` | The one campaign the daily watch monitors |
| `currency` | `USD` | Skill assumes USD; change here if not |
| `timezone` | `America/Los_Angeles` | All "today" / "24h" windows respect this |

## Budget guardrails

| Key | Value | Notes |
|---|---|---|
| `daily_budget` | `FILL ME` | Current campaign daily budget, in dollars |
| `daily_budget_hard_cap` | `FILL ME` | **The skill must never exceed this.** Set it deliberately |
| `micro_bump_step` | `1.00` | Per allowed auto-action B — $1/day, never more |
| `campaign_start_date` | `FILL ME` | `YYYY-MM-DD`. No auto-actions until start + 7 days (learning phase) |

## Leads — source of truth

| Key | Value | Notes |
|---|---|---|
| `lead_endpoint` | `FILL ME or leave blank` | Returns lead detail (scope, timeline, location, name, phone, email) |
| `lead_endpoint_auth_env` | `BRONCO_LEADS_TOKEN` | Name of the env var holding the token — **not the token itself** |
| `records_ad_id` | `false` | If `false`, leads are prorated across ads by share of daily spend |

Leaving `lead_endpoint` blank is supported but degrades the skill: it falls back to Meta's
`lead` action count and reports quality as *unknown*. Quality-weighted CPL — the metric the
whole skill is built around — requires this endpoint.

## Service area

| Key | Value | Notes |
|---|---|---|
| `service_area` | `FILL ME` | Towns counted as in-area; worth 1.0 of the 5.0 lead quality score |

## Auto-execute

| Key | Value | Notes |
|---|---|---|
| `auto_execute_enabled` | `false` | Start false. Flip to true only after a week of clean report-only runs |

Even at `true`, the skill's own limits still apply: one action per day, pause-or-bump only,
never activate/retarget/change creative, and a 7-day freeze after 3 actions in 7 days.

## Credentials

The Meta access token does **not** belong in this file or anywhere in this repo. Export it in
the environment that runs the schedule:

```
export META_ACCESS_TOKEN=...
```

A token with `ads_read` alone is enough for reporting. Pausing ads and changing budgets
additionally requires `ads_management` — without it, run report-only.
